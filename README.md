# FPV MENU
### by sanitar4ick · v.1.0 (release)

Внутриигровое меню для FPV Kamikaze Drone. Два оформления: Tactical и Cyberpunk.

## Запуск

1. Распакуй папку целиком в доступное для записи место. Файлы runtime должны оставаться рядом с загрузчиком.
2. При обновлении полностью закрой игру, затем запусти её заново.
3. Запусти `FPVInGame-Load.exe` из этой папки. Открой меню клавишей F6.

Не заменяй файлы уже загруженной сборки во время игры. F8 обновляет только диагностический отчёт.

## Страницы

| Страница | Содержимое |
|---|---|
| Weapon | Прицеливание, стрельба, выбор целей, части тела и клавиша активации |
| ESP/WH | Игроки, дроны, транспорт, предметы, рамки и подсветка моделей |
| Движение | Ультрабег, разгон транспорта и дронов, спидометр и колесо мыши |
| Телепорт | Clickwarp, выбранный и ближайший транспорт |
| Персонаж | Защита персонажа в собственном лобби |
| Профили | Сохранение, загрузка и удаление наборов игровых настроек |

Цвета и контуры заданы автоматически. Заливка рамок — 10%; рамки полные, с контуром. Погибшие персонажи и неактивные дроны отмечаются светло-серым. Дальность и выбор объектов остаются доступными. Масштаб исходного меню скрыт.

## Статусы

- Зелёный **(work)** — подтверждена работа у хоста и гостя.
- Жёлтый **(partial)** — работает частично, в зависимости от режима. Подробности доступны при наведении на заголовок раздела и функцию.
- Жёлтый **(only host)** — требуется собственное лобби.
- Красный **(test)** — рабочий результат пока не получен.

Подсказки появляются через 1,5 секунды. Статусы описывают проверенные сценарии текущей версии игры, а не обещают совместимость со всеми серверами и будущими обновлениями.

## Управление

| Клавиша / кнопка | Действие |
|---|---|
| F6 | Открыть / закрыть меню |
| Заголовок | Перетащить меню мышью |
| T в углу | Сменить тему |
| i в углу | Справка, версия, авторы и ограничения |
| F9 | Выключить функции, включая ускорение, Clickwarp и защиту |
| F7 | К ближайшему транспорту |
| СКМ / F10 | Выбрать или отменить точку при включённом Clickwarp |
| ЛКМ / Esc | Подтвердить / отменить Clickwarp |
| Колесо | Изменить предел помощи разгону на ±25 км/ч |
| F8 | Обновить диагностический отчёт |

Колесо меняет предел только при управлении техникой, включённом разгоне и закрытом меню. Пешком настройка не меняется. Пределы: транспорт 30–300 км/ч, ударный дрон 30–400 км/ч. Это предел помощи, а не жёсткий ограничитель физической скорости.

## Профили

Профиль включает Weapon, ESP/WH, движение, спидометр, управление колесом, Clickwarp и запрос защиты. Выбранная машина и текущая точка телепорта не сохраняются. Тема хранится отдельно. Загрузка профиля не снимает ограничений сервера.

В комплект включён профиль **«Рекомендую»**, сохранённый sanitar4ick. Открой страницу «Профили», выбери «Рекомендую» и нажми «Загрузить выбранный». Самостоятельно при запуске профиль не активируется.

Набор восстанавливается после подтверждения загрузки. Старые профили без дополнительных параметров поддерживаются: дополнительные режимы выключаются, а числовые параметры получают стандартные значения. При незавершённом сохранении повтори сохранение профиля. Для переноса профилей копируй папку `data/profiles` целиком — основная и дополнительная части нужны вместе. Другие личные профили и журналы в комплект не включены.

## Ограничения

- Ультрабег действует с Shift. На чужом сервере пешее ускорение и телепортация откатываются; требуется собственное лобби.
- Clickwarp в машине работает у хоста и на чужих серверах. Пешком требуется своё лобби: на чужом сервере персонажа возвращает назад. Поэтому общий статус функции — **(partial)**. Если СКМ пропускает нажатия, используй F10. При подтверждении ЛКМ возможен штатный выстрел; цель выбирается на достаточно ровной поверхности.
- Ускорение ударного дрона работает у хоста и на чужих серверах — **(work)**. На больших значениях может ухудшаться управляемость.
- Защита доступна у хоста. Включай её пешком; тело оператора остаётся защищённым при управлении ударным дроном, но сам дрон уязвим. Режим не лечит и не воскрешает. После истечения игрового эффекта режим выключается.
- Отдельные элементы ESP могут рисоваться поверх меню.
